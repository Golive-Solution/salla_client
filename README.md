# Salla ↔ ERPNext Integration

This app provides **two-way synchronization** between **ERPNext** and **Salla** for smooth eCommerce operations.

## Features

### From ERPNext → Salla
- Send **Item Master** to Salla  
- Update **Price List**  
- Update **Stock Balance**

### From Salla → ERPNext
- Send **Customer Master**  
- Send **Order Creation**  
- Send **Updates** (status/changes)  
- Configure Salla Orders to generate automatically as:  
  - **POS Invoice**  
  - **Sales Invoice**  
  - **Sales Order**

## Installation & Setup
1. Install the app in your ERPNext instance.  
2. Configure your **Salla API credentials** in the integration settings.  
3. Map synchronization options according to your business workflow.
